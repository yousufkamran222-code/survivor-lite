# Key findings (2026-11-15)

Read the tables below as shapes: 12 bot runs per cell (about ±14 points of noise), and the bot plays very differently from a person.

1. **The shop alone tops out around Virulence 5.** With every shop tier bought (~60k gold) and no Lab, the bot clears V4 reliably in all modes and wins V5 about 58% of the time (Infection 92%, Swarm 83%), V6 17-58%. That matches the design target ("fully upgraded clears 3-4, barely 5") quite well, a bit generous after the 2026-11-15 shop additions.
2. **The Lab is the real accelerator.** A fresh account (campaign sim: shop + Lab + ability, always the highest unlocked level) clears **V10 in 67-83 runs (2.5-4.3 hours)** while owning only **31-61% of the shop**. Genes buy far more power per run than gold. If V6-10 should be long-term goals, the Lab (or Genes income) needs to slow down, or the top levels need to get harder.
3. **Uneven steps.** Some levels fall in consecutive runs (Classic V3-V5 at runs 29-31; Infection V4-V7 at runs 16-21), then walls (Infection V8 at run 56, Nucleus V7 at run 46). A smoother ladder would make each level feel earned.
4. **First win timing.** Bot first V1 win: Classic run 4, Infection 1, Nucleus 1, Swarm 16. The target is a good player's first win after 3-5 runs, so Classic is on target, Infection and Nucleus are easier, Swarm is harder for the bot (it steers allies poorly).
5. **How to spend gold.** "Cheapest tier first" is as good as or better than the smarter buyers at almost every budget; damage-first is clearly worst until ~20k (survival matters early). Budget milestones in Classic (cheapest buyer): ~1k gold → V1 at ~50%; ~10k → V2 at ~67%; ~20k → V3 at ~67%; ~40k → V4 at ~50%; full shop → V5 at ~58%.
6. **Earning speed.** A fresh Classic account (no ads) reaches 1k gold by run 8, 5k by run 25, 10k by run 31, 20k by run 42. The full shop (~60k) isn't reached within the campaign: players hit V10 first (via the Lab).

# Economy report: what gold buys, and what the bot clears with it

Generated by `tools/sim/economy_sim.gd` + `tools/sim/campaign_sim.gd` (then `tools/sim/economy_report.py`). 12 runs per cell, seed 700. Shop only: no Lab, no ability, no Side Effects (the bot never takes them). The bot plays very differently from a person (no aiming, random-ish cards), so read win rates as a **shape** for comparing budgets and modes, not as what a good player will do. A cell is the bot's win rate at that Virulence; `·` = not run (the climb stops after the first level under 15%).

Full shop cost: **59886 gold**.
