# CLAUDE.md: Petri Panic (survivor-lite roguelite)

Read this first, then **`docs/SESSION_HANDOFF.md`** (full working context: owner, workflow, architecture, gotchas, balance, feedback history, backlog). With `docs/SPEC.md`, `docs/PIPELINE.md` and `docs/ROADMAP.md` that is enough to pick up the project cold. (`docs/HANDOFF.md` is the original pre-code planning handoff, kept for history.)

## What this is
A solo-dev mobile survivor-lite: drag to move, auto-attack, swarms, pick 1 of 3 upgrades per level, 5:00 runs, gold meta-progression between runs. Ships as a **native Android app**. The web build is a playtest tool only.
- Owner: Yousuf (A-Level student, ~6-8 h/week). He prefers concise explanations and **minimal, surgical changes** over rewrites.
- Working theme: **microbes in a petri dish** (white cell vs germs). It is not final (see `docs/DECISIONS.md`). Names, colours and text are data, so a re-theme is mostly a data edit.

## Engine and versions
- **Godot 4.7.2**, pinned in `GODOT_VERSION` (CI reads it). **Compatibility renderer only** (old GPUs, WebGL2, cheap phones).
- Portrait 720x1280, stretch `canvas_items` / `expand`.
- No addons yet. The AdMob/Firebase plugins arrive in milestone M3 and need the Gradle Android build.

## Commands (run from repo root)
```bash
godot --headless --path . --import                          # first time / after adding assets (run twice on a fresh clone)
godot --headless --path . -s res://tests/run_tests.gd       # all tests, exit 1 on failure
godot --headless --path . -s res://tools/sim/balance_sim.gd -- --runs 12 --seed 100   # balance report (JSON)
python3 tools/build_assets.py                               # regenerate assets/processed (needs numpy)
godot --headless --path . --export-release "Web" build/web/index.html   # needs export templates
```
The cloud sandbox can download Godot and the templates from GitHub releases and run all of the above. The web build can be screenshotted with Playwright plus Chromium (`--use-angle=swiftshader`) to check the UI.

## Architecture (keep it this way)
```
data/*.json          ALL tunable numbers: balance (incl. dash, chests, pickups, territory, conversion), enemies,
                     upgrades, evolutions, waves (incl. elites + the Nucleus wave table), meta, modes,
                     towers (Nucleus mode), online (leaderboards, achievements, score formula),
                     difficulty (the Virulence 1-10 ladder), lab (the Lab: Genes, branches, nodes, forks, keystones).
                     Tune here, not in code.
scripts/core/        Pure logic, no Nodes: World (the whole simulation), Territory (dish, tiles,
                     trail/claim flood fill, erosion), SpawnDirector, Upgrades, Lab (skill-tree rules), Progression
                     (XP, gold, run summary + score), Profile (persistent progress: stats, records,
                     achievements, merge), GameData (load + validate), BalanceBot. Deterministic.
scripts/game/        main.gd (screen flow + UI wiring), world_view.gd (draws World, effects, camera shake)
scripts/ui/          UiKit (theme, widgets, icon cards), HudOverlay (HUD, joystick, buttons),
                     IconArt (vector icons), UpgradeIcon, MenuBackground, MetaShop (upgrades shop
                     + popup), LabScreen (the Lab tree + popup), AbilitiesScreen (equip a Lab ability), DragScroll (drag-anywhere scrolling lists), BuildScreen (in-run paused build overlay)
scripts/autoload/    Save (Profile as versioned JSON), Analytics, Sfx, Ads (AdService + stub),
                     Online (accounts/leaderboards/achievements/cloud facade + StubOnlineBackend)
scenes/main.tscn     A single node. Everything else is built in code (hand-editing .tscn is fragile).
tests/               Headless tests: test_*.gd extends TestCase; the runner finds test_* methods.
tools/               build_assets.py (SFX synth), sim/balance_sim.gd (bot runs)
assets/processed/    Generated outputs (committed with their .import files). assets/raw/ = inputs.
```
- `World` owns all gameplay state as packed arrays (struct of arrays, swap-remove). It emits events (`hit`, `kill`, `nova`, `level_up`, ...) that `Main` turns into sound and haptics, and `WorldView` into effects. **Gameplay rules go in World, presentation goes in view or main.** Never put game logic in the view.
- Rendering: anything numerous (enemies, gems, bullets, shots, particles) goes through `SpriteBatch` (same-texture rects that the renderer merges; white textures generated by `ShapeTextures`, tinted per sprite; enemy eyes use a 16-direction atlas instead of rotation). The background is one tiled texture (`assets/processed/bg_tile.png`). Only a few things use `draw_circle` and friends. No per-enemy nodes. **Do not use MultiMesh**: it did not render in the WebGL build.
- `GameData.validate()` checks cross-references and runs in tests and at startup.

## Rules
1. **Run the tests before every commit/PR.** Add or extend tests for any logic change. Tests must be seeded and deterministic.
2. For any balance change, run the sim before and after and quote both in the PR (p10/p50/p90 survival time, win rate, level_p50).
3. **Ads go only through `Ads` (scripts/autoload/ad_service.gd), and online features only through `Online` (scripts/autoload/online_service.gd).** No SDK calls anywhere else. Web, desktop and tests use the stubs.
3b. **Saves:** never change the save format without bumping `Profile.VERSION` and handling old data in `Profile.from_dict()`. Never lose player progress.
4. Analytics only through `Analytics.event(name, params)`, with snake_case names of 40 characters or fewer.
5. **Never commit secrets**: keystores, passwords, service-account JSON, real AdMob IDs. CI injects them from GitHub secrets. Use AdMob **test IDs** in code.
6. Assets: CC0 only, and every non-generated file gets a line in `assets/MANIFEST.md`. Processed assets are rebuilt by `tools/build_assets.py`.
7. Prefer data edits over code edits, and small diffs over refactors. Don't rename or move files without a reason.
8. v1 scope cap: 1 character, 1 map, 8 or fewer enemy types, about 16 shared upgrades (incl. 5 dash cards), 4 evolutions (one per weapon), up to 4 tower types (Nucleus mode only, reusing the weapons), 4 Lab branches with 4 keystones (+ up to 8 abilities, phase 2), game modes are allowed (`data/modes.json`) (enforced by `tests/test_data.gd` and `tests/test_loot.gd`). Push new ideas to `docs/SPEC.md` "Later".
9. Turn playtest feedback ("dash feels floaty", "wave 4 too hard") into data changes first, using `balance.json` `juice` and `waves.json`.

## Performance budget (low-end Android is the target)
- On-screen enemies are capped by `waves.max_alive` (170). Scripted rings and splits may briefly exceed it, up to about 210.
- Caps: `perf.max_projectiles` 220, `max_enemy_shots` 120, `max_effects` 140, `max_damage_numbers` 40, `xp.max_gems` 120.
- Frame budget: 16.6 ms at 60 fps on the cheap test phone. Measure with `godot --headless --path . -s res://tools/sim/bench.gd` (per-subsystem ms/step during a kiting run): about 0.7 ms per step at 150+ enemies on a desktop CPU. Enemy separation runs for each enemy every `World.SEP_EVERY` (3) frames.
- The game steps once per rendered frame with dt clamped to 1/30 (`main.gd`), with no physics catch-up steps, so slow frames can't snowball.
- `balance.json` `debug.show_perf` shows FPS, enemy count and sim ms at the bottom of the screen. Turn it off before release. `debug.invincible` is for perf testing only and must stay `false` in commits. `debug.dev_tools` (Settings → Developer, behind the keypad code `debug.dev_password`: +10,000 gold, refund upgrades, all Virulence levels unlocked) is ON for playtest builds and **must be turned off for release**.
- To check rendering in the cloud, run the game under `xvfb-run -a godot --path . --rendering-driver opengl3` (real GL, screenshots via `get_viewport().get_texture().get_image()`), or export to web and drive Chromium with Playwright.
- No shaders, no textures larger than 512 px (exception: the 1024x64 generated enemy atlas), no per-frame allocations in hot loops where avoidable.

- `test.yml`: on every push and PR it runs the tests and a 4-run balance smoke, written to the job summary.
- **Web playtest build = itch.io** (`light213/petri`, channel `html5`; GitHub Pages dropped 2026-11-04, its deploy kept timing out). After each change the cloud session runs `tools/web_push.sh <butler>` (export + butler push; needs the web export templates, butler from broth.itch.zone, and `BUTLER_API_KEY` in the environment). `web.yml` is the manual backup (same push from Actions, repo secret `BUTLER_API_KEY`). ## Direction
`docs/ROADMAP.md` holds the plan: "you are the infection" = territory (B) + conversion (A).
**Game modes** (`data/modes.json`): each mode is a set of `overrides` deep-merged into `balance` by `GameData.apply_mode()` (e.g. Infection = territory on + its own XP curve; Classic = territory off). The menu picks the mode (`Save.mode`). Per-mode best times are in `Save.best_times`. Sim: `--mode <id>` (`--classic` still works). New features should be a new mode entry rather than a new toggle. Modes: Infection (territory), Swarm (conversion: allies are enemies with `e_team == 1` that follow a player-chosen **order** from a fan-out HUD menu (`World.set_ally_order`, `balance.conversion.orders`: Guard = bodyguard ring, Hunt = attack germs near you, Harvest = fetch stray gems); ally damage scales with enemy HP and might, and Outbreak boosts them; `query()` and the targeting helpers only return hostiles by default, and anything that loops over `e_pos` must skip allies itself), Classic. **Nucleus** (tower defence, `balance.defense` + `data/towers.json` + `waves.defense.waves`): germs march on a central nucleus from rim vents (switching to the player within `aggro_radius`), kills give biomass, standing on an empty pad shows a non-pausing tower bar (tap 1 of 4 to build; `World.build_tower`), standing on a built pad fills a ring to upgrade, the player respawns, only the nucleus dying ends the run; 12 waves, then COLLECT or endless Free Mode (`World.wave_def()` generates waves 13+); enemy HP/damage grow per wave, not per minute. State `defense_won` must be handled by anything that drives a World (sim, tests, Main). Upgrades can be limited to modes with `"modes": [...]`.
**Outbreak** (`balance.outbreak`, all modes): kills fill a meter (300); tapping the button starts a 5 s frenzy (weapons x1.6, damage x1.25, half damage taken, XP x1.5) plus a harmless gold blast that gilds nearby germs (`e_gild`, 0.5 gold each). **Per-mode difficulty** (`balance.difficulty`: `enemy_hp_mult`, `damage_taken_mult`, set in `modes.json`) tune each mode. **The bot win rate is a sanity alarm, not the target** (Yousuf, 2026-11-03): the bot plays very differently from people, so ±10-15 points either way is fine until playtests say otherwise; a big jump means something broke. Bot win rates (after XP x0.7, `xp.gain_mult`): Classic ~19%, Infection ~21%, Swarm ~15%, Nucleus ~31%. The real target is **a good player's first win after about 3-5 runs** with no permanent upgrades. Check with 48+ sim runs per mode after any balance change. **Kill streak** (`balance.streak`, World `streak`/`best_streak`): kills within 1.0 s chain; tiers and milestones drive the HUD; `best_streak` is saved (Profile v3) with 3 achievements; `streak.rewards` is the hook for future streak-triggered upgrades/abilities (empty = no gameplay effect). **Boss Rift** (`balance.rift`, **shelved 2026-11-04: `enabled` false**, code and tests kept for a later revisit): 5-10 s after an Outbreak a rift opens; inside (a far-off arena in the same World, the run frozen) you fight the Phage Carrier for 25 s and bait its Seeker Phage into it; win = a run-only Rift Power button from your strongest weapon; "dying" there ejects you at 1 HP with a 2.5 s frozen grace. Anything that drives a World must handle `rift_state` (see ROADMAP Prototype 4). **Virulence 1-10** (`data/difficulty.json`, `GameData.apply_virulence`): a per-mode difficulty ladder; win to unlock the next level, any unlocked level replayable from the mode card; each level adds a modifier plus a compounding HP/damage ramp; tuned so a fully upgraded account clears 3-4 and barely 5. Profile v4 stores cleared/selected per mode. Timed modes end on a **final minute** (from 4:00, `waves.final_minute_s`): germs x1.15 speed, elites every 20 s, bigger spawn budget, a FINAL MINUTE warning.

**The Lab** (phase 1 built 2026-11-05; `data/lab.json`, `Lab`, `LabScreen`, Profile v5): a second progression layer paid in **Genes** (first clear of a Virulence level pays `genes.first_clear[L-1]`, a repeat win `repeat_win`; granted in `Profile.record_run`). 4 branches × (4 play-changing nodes, a fork pair, a keystone, an ability node) in 7 tiers; **no Lab node repeats a shop stat**; a node opens when every lower tier of its branch has something owned; fork sides exclude each other; RESPEC refunds all Genes for `respec_gold`. Owned nodes become stats via `Progression.run_bonus` (shop + Lab), so World reads them from `stats` like any card; hooks live in World's "The Lab" section (middle: `crit`, `streak_dmg`, `overkill`, `arsenal`, `last_stand`, `recoil`, `feed`, `clot`, `momentum`, `refuel`, `evasion`, `wake`, `free_rerolls`, `start_levels`, `start_meters`, `treasure`; forks/keystones: `max_hp_pct`, `elite_damage`, `lysis`, `shield`, `iframes_pct`, `second_wind`, `dash_cd_pen`, `dash_phase`, `slipstream`, `head_start`, `extra_offers`, `mutation`; numbers in `lab.tuning`). Removed/repriced nodes are refunded on load by `Profile.migrate_lab` (`lab.retired` / `lab.repriced`). **Shop (Profile v6):** tiers split in two at the same caps (old level N → 2N on load, `Profile.META_SPLIT_V6`), ~1.7× the gold. **Scaling rule:** anything that scales with enemy HP (dash family, abilities, Rift Powers, Lysis, Volatile) divides out the Virulence part (`World._vhp()`, `difficulty.virulence_hp_mult`). Account sim: `tools/sim/campaign_sim.gd -- --mode ID --runs N --seed S` (a fresh profile climbs Virulence, buying cheapest-first). Sim: `--lab all|alt`, `--labx stat,...`. **Abilities** (phase 2, built 2026-11-05; `lab.abilities`): each branch ends in a tier-6 node that unlocks and levels one ability (Toxin → Stasis, Membrane → Engulf, Flagella → Cloak, Genome → Mitosis); ability level = that node's level; the equipped one is `settings.equipped_ability` (`Profile.equipped_ability/equip_ability`; no save bump); Main calls `World.equip_ability(id, lv)` after creating the World; the button sits left of DASH (the shelved Rift Power button moves further left if both exist); the meter fills with kills while the ability is inactive. World "Abilities" section: Stasis freezes enemies/shots/spawns/contact/core (`stasis_on()`, anything stepping enemies must respect it), Engulf grows `p_radius` and swallows non-elites, Cloak retargets hostiles to `cloak_pos` + an ambush window, Mitosis reruns `_update_weapons` from `clone_pos` with half-damage copies. Ability damage goes through `_ability_power()` (= dash scaling). Sim: `--ability <id> [--ability-level N]`; the bot fires it when crowded or below 40% HP.
